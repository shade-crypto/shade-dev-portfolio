# ShadeDev — портфоліо

Україномовний адаптивний сайт-портфоліо з трьома окремими демопроєктами.

## Як відкрити

1. Розпакуй папку `ShadeStudio`.
2. Відкрий її у Visual Studio Code.
3. Відкрий `index.html` у браузері або запусти через розширення Live Server.

Усі сторінки проєктів збережені в `projects/`. Стилі поділені на файли в `assets/css/`, а сценарії JavaScript — в `assets/js/` за окремими функціями: тема, меню, прокрутка, ефекти появи, космос, курсор, завантаження та копіювання Telegram-ніка.

## Структура

- `index.html` — головна сторінка портфоліо.
- `projects/` — три самостійні демосайти.
- `assets/css/` — змінні теми, базові стилі, космос, компоненти, адаптивність.
- `assets/js/` — невеликі незалежні сценарії для інтерактивних можливостей.
- `assets/images/` — іконка сайту.

Для вебшрифтів і фотографій потрібне підключення до інтернету. Без нього сторінки все одно відкриються зі стандартними шрифтами та кольоровим фоном. Щоб побачити всі ефекти, відкривай сайт через Live Server у VS Code.
